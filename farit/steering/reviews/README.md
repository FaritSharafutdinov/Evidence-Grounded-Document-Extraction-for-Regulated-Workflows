# External reviews

One file per external review: `YYYY-MM-DD-<source>-<topic>.md`

Sources: Gemini Deep Research (literature scans — full report goes to `papers/summaries/`, this file holds our analysis of it) or Gemini Argon teardown (artifact critique).

File structure:
1. **Source & date** — which model, what artifact was reviewed (link/path + commit hash).
2. **Verbatim or linked critique.**
3. **Our point-by-point response** — accept / reject (why) / action item (link to SPRINT or DEC).
4. **Outcome** — what changed in the project as a result (commits, decisions).
